Hybrid Intent Understanding Architecture
(Graph + Embedding + LLM)
Overview
This document describes a hybrid intent detection architecture that combines symbolic AI (ontology graphs and rule validation) with modern AI techniques (embeddings and large language models).
The goal of this system is to achieve:
Very high intent detection accuracy (≈98–99%)
Near 100% execution reliability
Explainable reasoning
Reduced dependency on LLM calls

The system follows the pipeline below:

User Query
   ↓
Tokenizer
   ↓
Ontology Graph Resolver
   ↓
Embedding Similarity
   ↓
LLM Semantic Reasoner
   ↓
Rule Validator
   ↓
Confidence Gate
   ↓
Intent Confirmation
   ↓
Execution

2. System Components
2.1 User Query
The system receives a natural language request from the user.
Examples:

Buy 10 Tesla shares

I want to invest in Tesla

Tesla looks bullish should I enter

Buy 10 Tesla shares

I want to invest in Tesla

Tesla looks bullish should I enter

Goal:
Convert unstructured text → structured intent representation
Example structured output:

Intent: BUY
Asset: TESLA
Quantity: 10


2.2 Tokenizer
The tokenizer performs text preprocessing and tokenization.
Tasks
• Lowercasing
• Removing punctuation
• Removing stop words
• Lemmatization
• Splitting text into tokens
Example
Input:

"I want to purchase 10 Tesla shares"
Normalized:

purchase 10 tesla share
Tokens:

["purchase", "10", "tesla", "share"]
Purpose
Prepare input for graph lookup and semantic analysis.
2.3 Ontology Graph Resolver
This is the first reasoning layer and deterministic system.
It uses a knowledge graph or ontology where synonyms map to parent intents.
Example ontology:

BUY_INTENT
 ├ buy
 ├ purchase
 ├ acquire
 ├ invest
 ├ go_long

SELL_INTENT
 ├ sell
 ├ exit
 ├ close_position
Graph relationships:

purchase → BUY_INTENT
invest → BUY_INTENT
sell → SELL_INTENT
Example
Tokens:

["purchase","10","tesla"]
Graph lookup:

purchase → BUY_INTENT
Result:

Intent = BUY
Confidence = 1.0
Performance
Metric
Value
Latency
~1 ms

100% deterministic

80–90%
2.4 Embedding Similarity
If the graph cannot resolve a token, the system uses semantic embeddings.
Sentence embeddings convert text into vector representations.
Example query:

enter a position in tesla
Graph lookup:

enter → unknown
Embedding similarity compares query vectors with intent phrase vectors.
Intent phrases:

buy stock
purchase shares
invest in stock
Similarity result:

enter position ≈ buy stock
Similarity score = 0.92
Predicted intent:

BUY_INTENT
Typical technologies
sentence-transformers
FAISS
vector embeddings
Performance
Metric
Value
Latency
5–10 ms
Accuracy
90–95%
2.5 LLM Semantic Reasoner
If embedding similarity is uncertain, the system calls an LLM to interpret the sentence.
Example query:

Tesla looks bullish should I get in
Prompt:

Classify the intent of this sentence:

Possible intents:
BUY
SELL
CHECK_PRICE

Sentence:
Tesla looks bullish should I get in
LLM Output:

BUY
LLM helps interpret:
• conversational language
• indirect intent
• complex phrasing
Example:

"I'm thinking about entering Tesla soon"
Intent detected:

BUY
2.6 Rule Validator
This stage ensures logical correctness before executing any action.
Example validation rule:

BUY_INTENT requires:
  asset
  quantity
Example query:

buy tesla
Detected:

Intent = BUY
Asset = Tesla
Quantity = missing
System response:

How many shares do you want to buy?
Another example:
Query

sell 50 tesla
Validation check:

User holdings = 0
Result:

Transaction rejected
This layer ensures execution safety.
2.7 Confidence Gate
Each layer produces a confidence score.
Example:
Layer
Confidence
Graph
1.0
Embedding
0.92
LLM
0.86
Decision rule:

if confidence > 0.9 → accept
else → clarification
Example clarification:

Did you mean BUY Tesla shares?
2.8 Intent Confirmation
Before execution, the system may confirm the detected intent.
Example:

Do you want to buy 10 Tesla shares?
User confirmation:

Yes
Intent finalized.
This step helps achieve near 100% execution reliability.
2.9 Execution
Once validated and confirmed, the system executes the action.
Examples:
• Execute trading order
• Call API
• Trigger automation workflow
• Run database query
Example structured output:

{
 "intent": "BUY",
 "asset": "TESLA",
 "quantity": 10
}

Synonym graphs must be updated over time.

Semantic similarity may occasionally misclassify.
LLM dependency
Rare ambiguous queries require AI reasoning.
